# NYC Taxi Trip Duration Predictor - Deployment

This directory contains the production deployment of the Neural Network model for predicting NYC taxi trip durations.

## 📁 Files

- `app.py` - Streamlit web application
- `requirements.txt` - Python dependencies
- `Procfile` - Heroku deployment configuration
- `runtime.txt` - Python version specification for Heroku
- `.streamlit/config.toml` - Streamlit configuration for deployment
- `pipeline_components.py` - Shared preprocessing transformers used by the pipeline
- `nn_sklearn_wrapper.py` - Sklearn-compatible neural network implementation
- `prepare_pipeline.py` - Script to (re)build the deployment pipeline
- `best_model.pth` - Pretrained neural network weights used by the pipeline script
- `nn_pipeline.pkl` - Trained model pipeline (generated by running prepare_pipeline.py)
- `model_info.json` - Model metadata and performance metrics (generated by running prepare_pipeline.py)

## 🚀 Setup & Installation

### 1. Generate Model Files

Before running the app, you need to generate the model pickle and metadata files:

```bash
python prepare_pipeline.py
```

This will:
- Load the training and test data
- Build the preprocessing pipeline
- Train the neural network model
- Evaluate on test set
- Export `nn_pipeline.pkl` and `model_info.json`

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

**Note:** If you have GPU support, install PyTorch with CUDA:
```bash
pip install torch==2.1.2 --index-url https://download.pytorch.org/whl/cu118
```

### 3. Run the Application

```bash
streamlit run app.py
```

The app will open in your browser at `http://localhost:8501`

## ☁️ Heroku Deployment

### Prerequisites

1. **Heroku Account**: Sign up at [heroku.com](https://heroku.com)
2. **Heroku CLI**: Install from [devcenter.heroku.com/articles/heroku-cli](https://devcenter.heroku.com/articles/heroku-cli)
3. **Git**: Ensure git is installed

### Deployment Steps

1. **Generate Model Files** (same as local setup):
   ```bash
   python prepare_pipeline.py
   ```

2. **Initialize Git Repository** (if not already done):
   ```bash
   git init
   git add .
   git commit -m "Initial deployment commit"
   ```

3. **Create Heroku App**:
   ```bash
   heroku create your-app-name
   ```

4. **Set Buildpack** (important for proper Python detection):
   ```bash
   heroku buildpacks:set heroku/python
   ```

5. **Deploy to Heroku**:
   ```bash
   git push heroku main
   ```

6. **Open Your App**:
   ```bash
   heroku open
   ```

### Heroku-Specific Files

The deployment includes these Heroku-specific files:

- **`Procfile`**: Tells Heroku how to run the Streamlit app
- **`runtime.txt`**: Specifies Python 3.10.12 for Heroku
- **`.streamlit/config.toml`**: Streamlit configuration optimized for Heroku
- **`requirements.txt`**: Updated with CPU-only PyTorch and gunicorn

### Deploying From a Larger Repository

If you keep additional experimentation code outside this folder, you can still push only the deployment assets using a subtree or by setting `APP_BASE=deployment` via the [monorepo buildpack](https://github.com/timanema/heroku-buildpack-monorepo).

### Troubleshooting Heroku Deployment

**App Crashes on Startup:**
- Check logs: `heroku logs --tail`
- Common issue: Model files not committed to git
- Ensure `nn_pipeline.pkl` and `model_info.json` are in the deployment folder

**Memory Issues:**
- Heroku free tier has 512MB RAM limit
- If you get memory errors, consider upgrading to paid tier

**Model Loading Issues:**
- Ensure pickle files are not corrupted during git push
- Check file sizes: `ls -lh *.pkl *.json`

**Streamlit Configuration:**
- The app is configured for headless mode (no browser auto-open)
- Server runs on dynamic port assigned by Heroku

### Heroku Environment Variables (Optional)

You can set these for better performance:

```bash
heroku config:set STREAMLIT_SERVER_HEADLESS=true
heroku config:set STREAMLIT_SERVER_PORT=8501
heroku config:set STREAMLIT_SERVER_ADDRESS=0.0.0.0
```

## 🎯 Using the Application

### Single Prediction Mode

1. Navigate to the **"Single Prediction"** tab
2. Enter trip details:
   - **Location:** Pickup and dropoff boroughs
   - **Time:** Hour, day, weekday, month
   - **Trip details:** Distance, passengers, payment type
   - **Financial:** Fare, tips, tolls, taxes
3. Click **"Predict Trip Duration"**
4. View the predicted duration in minutes

### Batch Prediction Mode

1. Navigate to the **"Batch Prediction"** tab
2. Upload a CSV file with the required columns
3. Click **"Predict All"**
4. View statistics and download results

### Required CSV Columns for Batch Mode

Your CSV must include these columns:

**Categorical:**
- `pickup_borough` (Manhattan, Queens, Brooklyn, Bronx, Staten Island)
- `dropoff_borough` (Manhattan, Queens, Brooklyn, Bronx, Staten Island)
- `payment_type` (credit card, cash, no charge, dispute)

**Numeric:**
- `passenger_count` (1-6)
- `trip_distance` (miles)
- `fare_amount` (dollars)
- `extra` (dollars)
- `mta_tax` (dollars)
- `tip_amount` (dollars)
- `tolls_amount` (dollars)

## 📊 Model Information

### Architecture
- **Type:** Medium-depth Neural Network (3 layers)
- **Structure:** 256 → 128 → 64 → 1 neurons
- **Activation:** ReLU
- **Regularization:** Batch Normalization + Dropout
- **Optimizer:** AdamW (lr=0.001)
- **Loss:** Huber Loss

### Performance (on 30% test set)
- **RMSE:** ~24.44 minutes
- **MAE:** ~3.15 minutes
- **R² Score:** ~0.298

### Why This Model?

This Neural Network was selected as the best performer among three models tested:

1. **Neural Network (Winner)** - Best RMSE, MAE, and R²
2. **XGBoost** - Second place, slightly higher error
3. **SVM** - Third place, significantly higher error

## 🔧 Technical Details

### Preprocessing Pipeline

The model uses a sophisticated preprocessing pipeline:

1. **Categorical Features:** One-hot encoding with column alignment
   - Ensures consistent features between training and prediction
   - Handles unseen categories gracefully

2. **Numeric Features - Mixed Scaling:**
   - **StandardScaler** applied to: `mta_tax`, `extra`
   - **PowerTransformer** applied to: All other numeric features
   - This handles different feature distributions optimally

3. **Neural Network:** PyTorch model wrapped in sklearn-compatible interface
   - Implements `BaseEstimator` and `RegressorMixin`
   - Supports GPU acceleration when available
   - Early stopping to prevent overfitting

### Custom Transformers

The pipeline includes two custom sklearn transformers:

- **`DummyEncoder`**: One-hot encoding with training column alignment
- **`MixedScaler`**: Applies different scalers to different feature groups

## 🛠️ Troubleshooting

### Model files not found
**Error:** `Error loading model: [Errno 2] No such file or directory: 'nn_pipeline.pkl'`

**Solution:** Run `python prepare_pipeline.py` from the parent directory to generate the model files.

### CUDA/GPU issues
**Error:** CUDA-related errors

**Solution:** The model automatically falls back to CPU. Install CPU-only PyTorch:
```bash
pip install torch==2.1.2 --index-url https://download.pytorch.org/whl/cpu
```

### Missing dependencies
**Error:** `ModuleNotFoundError: No module named 'xxx'`

**Solution:** Reinstall dependencies:
```bash
pip install -r requirements.txt
```

### Prediction errors
**Error:** Shape mismatch or feature errors

**Solution:** Ensure input data has exactly the required columns with correct types:
- All categorical columns must use exact values (case-sensitive)
- All numeric columns must be present
- No missing values allowed

## 📝 Notes

- The model expects input features in the same format as training data
- All categorical values are case-sensitive
- Borough names must match exactly: "Manhattan", "Queens", "Brooklyn", "Bronx", "Staten Island"
- Payment types: "credit card", "cash", "no charge", "dispute"
- The pipeline automatically handles feature scaling and encoding

## 🔄 Retraining

To retrain the model with new data:

1. Update `train_70.parquet` and `test_30.parquet` in the parent directory
2. Run `python prepare_pipeline.py`
3. New `nn_pipeline.pkl` and `model_info.json` will be generated
4. Restart the Streamlit app to load the new model
